# Imran House — Living House Demo (BBB)

Interactive concept demo of the BBB "Living House" product, built on the frozen
V19 concept model of Imran House, Serla, Bhimber (AJK, Pakistan).

- `index.html` — the product demo shell (A/B field versions, Urdu)
- `imran-house-explorer.html` — the living model: walk-through, 23-stage build
  sequence, room finish switcher, furniture placement, automatic plan checks

CONCEPT — NOT FOR CONSTRUCTION. All geometry is a concept model for client
understanding; it is not an engineering or fabrication drawing set.
