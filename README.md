# Imran House — Living House (BBB)

The BBB "Living House" product, proven on the frozen V19 concept model of
Imran House, Serla, Bhimber (AJK, Pakistan). One model, three faces:

- `index.html` — the field demo (Urdu): A/B versions, the interactive
  Explorer, 12 photoreal finish views QA-checked against the model, the 4D
  build film, and a model-true front elevation.
- `imran-house-explorer.html` — the living model itself: walk-through,
  54-stage build sequence, object layer (84 columns · 48 beams · 33 lintel
  bands · 18 window units · 790 furnishing items), 9 programme checks + the
  full 23-rule cross-trade conflict matrix, room finish switcher,
  ghost-snap furniture placement, missions, living day/evening layer, real
  solar sun & time for Bhimber, model-measured estimate panel, room & door
  search, camera bookmarks, a movable section cut, and PNG screenshots.
- `client-studio.html` — the Client Studio for NEW houses: measurements
  in → a furnished house builds itself stage by stage. Three intake paths:
  automatic concept from plot + family needs; a basement and true
  trapezoid plots supported; and the client's OWN plan, entered room by
  room with a named human confirmation for every measurement (the layout
  never silently shrinks a confirmed room). Every generated plan passes an
  executable 8-point QA gate (entry, reachability, no invented rooms,
  shape, stair hall, windows, wet-room vents, stack discipline, scale)
  whose results are printed in the client's own summary.

CONCEPT — NOT FOR CONSTRUCTION. All geometry is a concept model for client
understanding; it is not an engineering or fabrication drawing set.
Estimates shown are benchmark bands, never quotations. Items the data
cannot verify are labelled NOT VERIFIED in the apps themselves.
